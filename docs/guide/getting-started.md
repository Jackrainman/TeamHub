# 队员上手指南（5 分钟）

队长已经把 TeamHub 跑起来并发给你网址后，从首页开始安排本周任务。

## 第一次打开

1. 打开队长发的地址，输入名册中的用户名登录。首次登录后按提示设置密码；密码至少 8 位，同时包含字母和数字。
2. 之后使用用户名和密码登录。忘记密码时请队长在设置页重置，不需要自己操作服务器。
3. 身份模式下，周任务操作必须登录。匿名模式可查看全队任务，但不能自报、认领到本周或验收周任务。

## 本周任务怎么做

1. 首页默认显示本周、我的、进行中。点“自报任务”，填写组、标题、要完成什么等信息；承担者自动是你，不需要再选名字。
2. 想接已有工作，切到“任务池”，点“认领到本周”。这里一直显示当前没人认领的活动任务，不受所选历史周影响。
3. 点左侧任务标题，在右侧查看事实和操作；也可打开完整详情。卡住时记录等哪个任务、缺什么条件。这里展示结构原因，不评价谁快谁慢。
4. 完成后点“标记完成”，任务进入“已完成”的待验收状态。另一名成员切到“全队 → 已完成”，打开详情后验收；承担者和完成人不能自验。验收后卡片保留双方名字与时间。
5. 需要返工时由另一成员打回并说明理由。任务回到进行中，再次完成后需要重新验收。
6. 做不下去时，可在进行中任务的详情里退回任务池；本人或本组组长可操作，任务历史保留。

## 回看过去的周

用周标题旁的箭头查看历史周。每周按上海时间周一至周日计算；历史页显示“那周关联过的任务及最新结果”，不是当时周日的状态快照。

历史详情只读。尚未完成的本人任务可点“延续到本周”，继续使用同一张任务卡；不会复制任务，也不会生成个人截止日期。第一版不能创建未来周计划。

“我的”始终指登录的你；“全队”展示任务事实，没有筛选其他成员、个人任务数或完成率。

## 页面入口

| 页面 | 用途 |
|---|---|
| 本周 | 周任务、自报、认领、完成、验收和历史周查看 |
| 总览 | 汇报倒计时、本车与赛季进度、六阶段、完整基准线与门检查 |
| 项目 | 默认三列看板，可切全赛季依赖图和全局任务池 |
| 队伍近况 | 近况规划说明与只读赛季基准线 |
| 每日在场 | 资源时段与接力协作 |
| 学习方向 | 查看结构性的技能缺口 |
| 时间线 | 回看项目事实 |
| 知识库 | 按症状搜历史卡片，点“新建归档”记录根因与处理，自动关联当前项目 |
| 图纸档案 | 按机构和版本管理图纸 |
| 库存 / BOM | 查余量、装拆、入库、报损与缺料 |
| 报销 | 票据本地导入、条目登记、材料自证和选中条目导出 |
| 机器人清单 | 整机检查项与门检查 |
| 设置 | 侧栏自动收起、字号、名册与权限、语言及七套主题 |

入口会随队伍启用的模块变化。总览、每日在场等入口在侧栏“更多工作区”中。队伍近况尚不能发布动态。

侧栏空闲 4 秒会自动收起，操作侧栏重新计时；手动展开后保持到刷新。可在设置页关闭自动收起。Ctrl/⌘+K 打开全局搜索，检索任务、知识库与库存。

## 常见问题

- **找不到用户名**：请队长检查设置页名册。
- **重启后还要登录吗**：会话保存在 SQLite，正常重启后有效会话继续可用。登出、过期或密码变更后需要重新登录。
- **我的信息会被拿去排名吗**：不会。名字只用于任务卡和事实时间线，不生成成员排名或产能比较。
- **主题和字号怎么换**：在设置页选择；新用户默认使用 E 版深色，已有主题选择保留。字号支持标准、大、特大，选择保存在本机浏览器。

修完问题留一份结案记录，动了零件记一笔库存，图纸更新上传新版本，这些记录能让后续接手的人少走弯路。
