# 队员上手指南（5 分钟）

> 你是谁：战队队员。队长已经把 TeamHub 跑起来了，发给你一个网址。
> 这页告诉你怎么登录、每天看哪里、以及三个最常用的动作。

## 第一次打开

1. 浏览器打开队长发的地址（形如 `http://192.168.x.x:4177`，手机电脑都行）。
2. 去**设置页登录**：在名单里找到自己的名字。**第一次登录不需要密码**，登录后自己设一个 PIN，
   下次就用它。**PIN 设了就别忘**——目前产品里没有一键重置，忘了得让队长上服务器手工清（麻烦他）。
3. 如果打开就能直接用、没有登录入口，说明队里部署的是匿名模式——跳过这步即可
   （匿名模式下「我的视图」页不可用，其余一样）。

## 每天三个动作

1. **开「我的视图」**：只显示你的任务——哪些现在就能动手，哪些被上游卡住暂时做不了。
2. **没活了去领一个**：「项目」页的**挂单池**里放着没人认领的活，看对眼就认领，认领即生效。
3. **卡住了就说出来**：在任务上登记你在等哪个任务、缺什么东西。系统会把卡点画在依赖图上，
   让它替你开口——**这里显示的是"任务被什么卡住"，永远不显示"谁慢了"**，放心记。

## 三个好习惯（帮未来的自己）

- **修完 bug 顺手结案**：知识库页把这次的症状和解法归档。明年学弟撞上同款串口乱码时，
  搜一下就能翻到你的解法。
- **动了零件记一笔**：装车、拆车、领用、报损，在库存页记一笔账，全队都知道家底还剩多少。
- **图纸更新就上传**：图纸档案页按机构、按版本存，别让最新版只躺在你自己的电脑里。

## 九个页面都是干嘛的

| 页面 | 你会用它来 |
|---|---|
| 总览 | 看离比赛还有几周、全队进度比计划快还是慢、哪些门检查没过 |
| 我的视图 | 看自己的任务：能动手的 / 被卡住的（需登录） |
| 项目 | 建任务、看板追进度、依赖图看谁卡谁、挂单池领活、标完成和验收 |
| 知识库 | 遇到问题先按症状搜历史坑；解决后结案归档 |
| 图纸档案 | 找某个机构的最新图纸；上传新版本 |
| 库存 / BOM | 查零件余量；装拆 / 入库 / 报损记账；看缺料提醒 |
| 机器人队 | 看整机状态；排今天谁在场、车怎么接力 |
| 学习方向 | 按工种（机械 / 电控 / 程序）看队里缺什么技能，规划自己往哪补 |
| 设置 | 登录登出、切中英文、切深浅色主题 |

## 常见问题

- **登录不上 / 名单里没有我**：找队长——名册由队长在设置页导入维护。
- **忘了 PIN**：找队长——目前没有界面上的重置按钮，队长需要在服务器上手工清掉你的 PIN 记录
  （操作步骤在部署指南里），之后你重新登录再设一个。
- **服务重启后要重新登录**：正常现象，会话不落盘；重新选自己名字输 PIN 即可。
- **我填的东西会被拿去排名吗**：不会。这是产品底线：系统不做任何"谁快谁慢"的排名和统计，
  你录入的信息只用来显示任务状态和帮你正名"我是被卡住的，不是在摸鱼"。

有别的问题或建议，直接跟队长说——公测阶段每条反馈都有用。
