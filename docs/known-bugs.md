# Known Bugs / 未修复问题

> 记录已知 bug 以及用户反馈的未修复问题。按发现时间逆序排列。

## 2026-08-03

### 导入名册页 CSV 上传严重性能问题（暂不修）

- **影响范围**：hub-console 名册导入页（CSV 上传）
- **描述**：上传 CSV 时出现严重性能问题，甚至把浏览器卡到未响应；最终仍能正确上传（数据无损）
- **预期行为**：上传/解析过程流畅，不阻塞 UI
- **严重程度**：高（体验），数据正确性不受影响
- **可能原因**：未排查（疑似解析/预览同步阻塞主线程或逐行重渲染）

### 日期选择器深色主题下不可见（暂不修）

- **影响范围**：hub-console 日期选择器（深色主题）
- **描述**：日期选择器面板太黑，深色背景下看不到内容
- **预期行为**：深色主题下面板/文字对比度足够，应为白色（亮色）呈现
- **严重程度**：中（可用性）
- **可能原因**：原生 date input / 弹层未跟随 `[data-theme]` token，用了硬编码暗色

### 主页信息过载、初始化动线缺失（暂不修，UX 设计项）

- **影响范围**：hub-console 主页 / 首次使用动线
- **描述**：主页内容太多，老用户也不知从何开始初始化；关键初始化动作（如强制上传一台车）缺乏引导动线
- **预期行为**：设计初始化使用动线（onboarding），把「必须先做什么」显性化
- **严重程度**：中（新用户上手门槛）
- **备注**：属 UX 设计项而非代码缺陷，待动线设计立项
