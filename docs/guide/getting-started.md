# 队员上手指南（5 分钟）

队长已经把 TeamHub 跑起来并发给你网址后，从首页查看全队任务、记录自己要做的事。

## 第一次打开

1. 打开队长发的地址，输入名册中的用户名登录。首次登录后按提示设置密码；密码至少 8 位，同时包含字母和数字。
2. 之后使用用户名和密码登录。忘记密码时请队长在设置页重置，不需要自己操作服务器。
3. 登录后可以创建和推进自己的任务，并验收选了你作为备位的任务。

## 创建、完成与验收

1. 首页默认显示自己的进行中任务，右上角可切换“个人 / 全队”及 2、3、4 列排版。点“新建任务”，填写小组、标题和要完成什么；创建后即可开始。点击卡片会居中打开详情。
2. 备位人可多选，也可以先不填。后续打开详情，点“编辑任务 / 选择备位人”补选或替换。
3. 完成后点“标记完成”，任务变为待验收；没选备位人也能完成，作者之后再补选。
4. 选定的备位人切到“全队”，状态选“待验收”，打开任务详情点击“已验收”，一人通过即可。其他成员仍能查看学习；作者和完成人不能自验。
5. 需要返工时，备位人填写原因退回。任务回到进行中，再次完成后重新验收。
6. 作者修改已验收任务的标题或说明后，需要重新验收；只更换备位人不撤销已有结论。

任务页的“任务教程”提供固定交互 Demo，可依次练习创建、选择备位、标记完成、切换验收人视角、通过或打回；演示不会修改真实任务。教程中的“完成留存”指验收通过后任务与事实历史自动保留，不需要另行手动归档。

## 查询历史

任务与进展自动保存，不需要手动归档。可按小组、状态筛选，或搜索标题、说明和旧内容；打开详情可查看修改、备位更换与验收记录。

全队能查看任务事实，不提供其他成员筛选、个人任务数或完成率。

## 页面入口

| 页面 | 用途 |
|---|---|
| 任务 | 个人 / 全队任务、自建、备位验收及历史查询 |
| 总览 | 汇报倒计时、本车与赛季进度、六阶段、完整基准线与门检查 |
| 项目 | 默认三列看板，可切全赛季依赖图和全局任务池 |
| 队伍近况 | 近况规划说明与只读赛季基准线 |
| 每日在场 | 资源时段与接力协作 |
| 学习方向 | 查看结构性的技能缺口 |
| 时间线 | 回看项目事实 |
| 知识库 | 按症状搜历史卡片，点“新建归档”记录根因与处理，自动关联当前项目 |
| 图纸档案 | 按机构和版本管理图纸 |
| 库存 / BOM | 查余量、装拆、入库、报损与缺料 |
| 报销 | 票据本地导入、条目登记、材料自证和选中条目导出 |
| 机器人清单 | 整机检查项与门检查 |
| 设置 | 侧栏自动收起、字号、名册与权限、语言及七套主题 |

入口会随队伍启用的模块变化。总览、每日在场等入口在侧栏“更多工作区”中。队伍近况尚不能发布动态。

侧栏空闲 4 秒会自动收起，操作侧栏重新计时；手动展开后保持到刷新。可在设置页关闭自动收起。Ctrl/⌘+K 打开全局搜索，检索任务、知识库与库存。

## 常见问题

- **找不到用户名**：请队长检查设置页名册。
- **重启后还要登录吗**：会话保存在 SQLite，正常重启后有效会话继续可用。登出、过期或密码变更后需要重新登录。
- **我的信息会被拿去排名吗**：不会。名字只用于任务卡和事实时间线，不生成成员排名或产能比较。
- **主题和字号怎么换**：在设置页选择；新用户默认使用 E 版深色，已有主题选择保留。字号支持标准、大、特大，选择保存在本机浏览器。

修完问题留一份结案记录，动了零件记一笔库存，图纸更新上传新版本，这些记录能让后续接手的人少走弯路。
